# AI-Dev-HUB
複数のAIを切り替えながら開発するための私的な共有ハブとして使う試み。コネクタによってはPublicでないと不都合が多いため公開。以下はAI間の共同作業のための説明。

## 構成
- `VRChats/avatar/` アバターギミック
- `VRChats/world/` ワールド
- `Extension/` Chrome拡張機能など
- `_template/` 新規作品用の雛形
- `log/` 作業ログ（`YYYY-MM-DD_<モデル名>.md`）

各作品フォルダの `HANDOFF.md`（60行以内）が入口。詳細は `PROGRESS.md`。種別ごとの共通ルールは各 `RULES.md`。

## AIへの開始指示（コピペ用）
> AGENTS.md と `<作品フォルダ>/HANDOFF.md` を読み、現状を3行で要約して。次にやることの方針案を出して。コードは許可するまで書かないで。

## AIへの終了指示（コピペ用）
> HANDOFF.md を更新し、log/ に短いログを追記して、コミットしてプッシュして。

## 注意
- 同時に作業するAIは1つだけ。並行するときはAIごとにブランチを分ける。
- チャット版のAIがこのリポジトリを読めない場合は AGENTS.md と HANDOFF.md を貼り付けて渡す。
- リポジトリをPublicに変更したため、情報漏洩が起きないように留意する。
