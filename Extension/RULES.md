# 拡張機能（Chrome等）共通ルール
- Manifest V3。権限は最小限にする。
- 作品ごとのZIP命名・バージョン規則は、各作品の `HANDOFF.md` の `## 作品ルール` に書く。
- 新規作品は `_template/` をコピーして `Extension/<拡張名>/` を作る。
- 作品フォルダにはソース一式を置いてよい。`node_modules/`・ビルド出力・e2e の作業フォルダはコミットしない（各作品の `.gitignore`）。
- **AI間のスコープ衝突防止**: 依頼された機能・ファイルのみを変更する。他AIの直前コミットや作業中ファイルを不用意に巻き戻し・一括置換しない。
