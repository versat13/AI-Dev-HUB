# ストア掲載用メモ（Chrome Web Store）

## 名前
ScrapAI

## 概要（132字以内）
ページ・X投稿・GitHub・掲示板スレを、ボタンを押したときだけ端末内に保存。後から検索して、AIに解説させるプロンプトも作れます。データは外部に送りません。

## 詳細説明（案）
- 保存はボタン（またはショートカット・右クリック）を押したときだけ。保存先はブラウザの中だけで、外部送信・同期はしません。
- 範囲選択の断片を同じページに複数追加できます。X・GitHub・ふたばは専用の抽出ルールがあり、ルールは自分で編集できます。
- AI連携はコピー＆貼り付け方式です。テンプレートからプロンプトを作り、ChatGPT・Claude・Geminiを開き、回答を貼ると見出しごとに整理して保存します。英語の本文は日本語訳を適用できます。
- JSONでエクスポート/インポート。

## 権限の説明（審査用）
- activeTab / scripting：保存を実行した時点の現在のタブから本文を取り出すため。常時のサイトアクセスはしない（host_permissionsなし）。
- storage / unlimitedStorage：設定と、保存したスクラップをローカルに保存するため。
- sidePanel：サイドパネルで一覧を見るため。
- contextMenus（任意）：設定でオンにしたときだけ右クリックメニューを出すため。

## 単一目的
ユーザーが選んだWebページの内容を端末内に保存し、後から探して、AIに渡すプロンプトを作れるようにする。

## プライバシー
`PRIVACY.md` を公開URLに置いて指定する（GitHub Pages等）。収集するユーザーデータ：なし（すべて端末内）。
