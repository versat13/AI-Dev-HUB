# 作品ルール記載例（コピーして各拡張機能のHANDOFF.mdに貼る）
## 作品ルール
### 配布ZIP
- 名前：`<拡張名>_v<MAJOR>.<MINOR>.<PATCH>.zip`（初回 v1.0.0）
- ZIPは「ZIP作って」と指示があった時のみ作成。作成のたびにPATCHを+1
- MAJORは「メジャーアップデート」の指示時のみ+1（MINOR/PATCHは0に戻す）。MINORは指示時のみ
- 出力先：`dist/`（過去のZIPは削除しない）
### フォルダ名
- 開発フォルダ `<拡張名>/` は絶対に変更しない
### バージョン同期
- ZIP作成時、`manifest.json` の `"version"` もZIP名と同じ数字にする
### テスト
- 変更後は「拡張機能ページで更新→対象タブをリロード」で確認する旨を案内する
