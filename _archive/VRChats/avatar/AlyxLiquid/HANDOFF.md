## 目的とユーザーの方針
- Half-Life: Alyx の酒瓶の液体を VRChat アバターギミックで再現(手持ちの丸いウォッカ瓶、汎用。テストはテスト用アバター)
- 最優先は「水面の動きのリアルさ」。重い表現(SSS 等)は使わない。小細工は逆効果になりやすい → **ベンチで計測し、効果の大きい順に直す**
- 応答は簡潔・結論から。**コードを書く/変更する前に方針を短く示して許可を得る**
- 気泡は無効(不評)。壁際の泡は可。泡は細かい粒で(ベタ塗り不可)

- テスト用シーン: メニュー「AlyxLiquid Test」(Vodka 左手 / 赤ワイン色)、瓶 0.8 倍・残量 0.6
- ユーザーの C ドライブが満杯になったことがある。大量に書き出す前に空きを確認

## 仕組み(要点)
- 液体 = SkinnedMeshRenderer + 独自シェーダー。PhysBone の振り子 2 本(速い Gimbal 約 3.5Hz / 遅い Gimbal2 約 1.3Hz)の向きを、特殊バインドポーズで法線とタンジェントに載せてシェーダーに渡す(同期は Transform 由来で追加パラメータなし)
- 液面 = 体積保存 LUT の平面 + 高さ場(一次スロッシュ、高次モード、表面波、壁リング)をレイマーチで描画
- 描画順: 液体 2899 → lilToon 屈折ガラス 2900(逆だと液体が消える)

## 今回やったこと
1. **アバター拡大縮小で液面が追従しない不具合を修正**: SMR の行列スケールが更新されないため、振り子ボーンが運ぶ法線の長さ(= 0.5 × 実スケール)で補正。0.5〜2 倍で一致を確認。元は液体が約 1.2 倍大きかったのも解消。**VR 実機で未確認**
2. **進め方を改訂(承認済み)**: 瓶全体の描画の作り直しは取りやめ → 1 ベンチ → 2 揺れの較正 → 3 映り込み・光 → 4 厚み・屈折を部分的に → 毎回負荷計測
3. **ベンチ作成**: `Assets/AlyxLiquid/Dev/AlyxBench.cs` + `AlyxLiquid_Bench.unity`(開発専用)。Play で 4 動作(shake / tiltstop / flick / swirl)を自動再生し、`AlyxDebug/bench/<runTag>/` に一覧画像と振り子角度の CSV を出力。runTag を変えて前後比較
4. **揺れの較正(手順 2 の前半)**
   - 計測: 振れ幅が物理の見積もりの約 2 倍、遅い振り子が 170° 超まで回って反転
   - PhysBone の角度制限は使えない(瓶基準なので、瓶を傾けると振り子が真下を向けなくなる)→ 骨の長さで較正
   - プレハブ: GimbalTip 0.01→**0.025**、Gimbal2Tip 0.02→**0.10**。swirl 定常 35°→16°(見積もり 17°)、shake 72°→40°(見積もり 43°)、反転なし
   - シェーダー: 遅い振り子の角度を `_SlowMaxDeg`(45°)で頭打ち。振られている最中は余韻を弱める `_ResidualMask`(20°)を追加
   - 前後比較の GIF を送付済み(calib1_before_after.gif)
